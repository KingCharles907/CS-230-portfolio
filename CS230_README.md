# CS 230 - Operating Platforms

## Software Design Document

In CS 230, I worked on a project for The Gaming Room. The goal was to design a game called Draw It or Lose It that could work on different devices.

### 1. Who was the client and what did they want?

The Gaming Room wanted to take their Android game, Draw It or Lose It, and make it available on other devices. They wanted players to be able to play online, join teams, and have their own unique names and IDs.

### 2. What did I do well?

I think I did a good job explaining the different operating systems and how they could support the game. I also explained why I chose Windows Server and how it could help the company run the game.

### 3. What did I find helpful about the design document?

The design document helped me understand how everything should work before jumping into coding. It made it easier to see how the different classes connect and what the program needs to do.

### 4. What would I improve?

I would spend more time comparing the cost and performance of each operating system. I would also add a better diagram showing how the game, server, and database communicate with each other.

### 5. How did I understand the user's needs?

I focused on making the game easy to access from different devices. I also made sure the design included different teams, players, and unique IDs. Understanding what users need is important because nobody wants to use a program that doesn't work the way they expect.

### 6. How did I approach designing the software?

I started by looking at what the client wanted and then compared different operating systems. I looked at security, storage, memory, and how the game would work online. In future projects, I would use the same approach and try to test things earlier so problems can be caught before they get bigger.
